# 知识库分两层:事实层与结论层

视频入知识库时存两层。事实层(Source Layer)是 bundle 原始产物(转写、帧图、manifest、context.md)的原样沉淀;结论层(Conclusion Layer)是 agent 基于事实层产出的分析结果,挂靠对应事实层条目。结论层可随时删除重跑,事实层永不覆盖。

理由:ASR 引擎与术语修正表会升级,分析角度会变,而抖音/B站链接会失效——只有事实层保真沉淀,重分析才永远可能。只存结论等于把知识库的根扎在易变的东西上。

## Consequences

- 事实层产物必须自带版本信息(工具版本、ASR 模型、术语表指纹),否则"旧事实层要不要重采"无法判断。
- 重新分析新视频时,应先查事实层是否已有该 video_id,避免重复下载解析。
