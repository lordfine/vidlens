# Skill 与 CLI 完整改造计划

用户已授权全部优化方向，并由执行者按推荐顺序确定设计与测试接缝。审查基线为提交 b1f3bf0，范围包含其后的未提交 Skill 与 CLI 改造。

## 要求与完成条件

1. Agent 契约：普通成功和失败均为结构化 JSON；参数错误退出 1，登录错误退出 2，网络／风控退出 3，依赖错误退出 4；失败带可执行 hint。显式帮助和版本查询保留常规 CLI 行为。输出文件路径为绝对路径。显式帧上限始终生效。
2. 缓存：刷新沿转写、WAV 和分块生效；源内容、识别引擎或术语修正表改变时不能复用旧转写；下载只能确认本次对应媒体产物，失败不得破坏原有缓存；两个视频来源统一报告缓存命中、取得来源及重试。
3. 集中编排：subs、transcribe、prepare 共用字幕／转写准备模块；保留字幕优先、强制识别、禁止识别、登录／风控错误透传、原音频保留等行为。清单包含工具、引擎、模型和修正规则的来源信息。
4. 配套分发：发布版本升级，CLI 提供机器可读能力与协议版本，Skill 能核对实际调用的 CLI；根目录 SKILL.md 为唯一来源。CI 验证源码包、wheel、隔离安装后的 CLI 与技能安装，既有文件保护和无硬链接环境可用。
5. 本地素材：meta、subs、transcribe、frames、prepare 接受本地视频或音频；源文件不被改写，派生数据进入管理缓存。支持显式字幕文件以离线处理已有字幕。
6. 可搬运素材包：提供独立导出命令，复制所需媒体和证据，内部引用均相对于导出目录；搬到新目录并移除原缓存后仍可核验引用与读取。原素材包不被修改，不覆盖现有导出内容。

## 设计选择

- 保留视频来源适配器和下载契约；增加本地文件适配器，取媒体和字幕的差异在现有接缝内处理。
- 将字幕选择、错误分类、ASR 调用、文本产物及来源记录集中到一个准备模块，CLI 和素材包只表达用途。
- 使用源文件内容指纹和派生规则版本确认缓存；通过临时文件及原子替换发布完整产物。
- 导出生成清单驱动的独立副本，拒绝把意外路径或未引用文件混入素材包。
- 不引入数据库、检索索引、浏览器登录自动化或远端发布。

## 测试接缝

公开 CLI 的 JSON／退出码与可见产物；视频来源 download 接口；字幕／转写准备模块；真实 FFmpeg 的合成媒体链路；隔离安装后的分发行为。每项先建立能复现旧行为的失败测试，再实现和验证。外部站点和识别推理在离线回归中可使用适配器替身，真实本地链路另行验证。

## 最终核验

执行 ruff、完整离线 pytest、doctor、本地真实媒体命令、素材包搬迁核验、源码包和 wheel 构建及隔离安装检查；按编码规范和本计划分别进行独立审查，修正后复核。最后安装本机全局 CLI 和 Agent Skill，提交并推送 GitHub，核对本地与远端提交一致。
